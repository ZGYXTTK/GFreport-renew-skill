# 工具清单.jsonl（Step 2 输出）

> Agent 在 tools/list + smoke test 后，逐行追加写入 `runs/<run-id>/sources/工具清单.jsonl`。

每行格式：

```json
{"source":"QVeris","kind":"registry","present":true,"smoke":"ok","discovered":true,
 "found_tools":["..."],"note":"..."}
```

字段说明：
- `source`：源名（必须与 `config/tool_registry.json` 一致）
- `kind`：registry/api/http/agent/plugin
- `present`：是否在本机安装
- `smoke`：ok / degraded / fail / none
- `discovered`：仅 kind=registry 必填，是否执行过 discover
- `found_tools`：仅 kind=registry 必填，discover 返回的工具名列表
- `note`：补充说明

未实测禁止标 ok → 标 none 或 fail。`tool_inventory.py` 会机检：
- 缺聚合器探查 → 阻断
- 未测标 ok → 警告
- 注册表内源未盘点 → 阻断
